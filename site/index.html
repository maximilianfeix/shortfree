    How it works

    1. Sweep

      Every valid label (a–z, 0–9, inner hyphens) is asked for at the TLD's authoritative name servers. NXDOMAIN means the name is not in the zone.

    2. Verify

      1–3 character candidates are looked up in the registry's RDAP service. 404 means not registered. Names in redemption or pending delete are listed as dropping.

    3. Repeat

      A GitHub Action runs daily: 1–3 characters every day, the 1.8 million 4 character names per TLD in seven daily shards.

    "Free" means not registered at the last scan. Registries may still reserve a name or price it as premium, and names can change state between scans. Your registrar shows the final price. For a live answer, use shortfree check or the MCP server.
